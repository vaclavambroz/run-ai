# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.4.1] - 2026-11-12

### Added
- Initial public release under MIT license
- Provider-neutral tmux session launcher (Codex, Claude, Gemini)
- Workflow planning with tamper-evident plan digests
- Audit receipts: canonical, secret-free JSON launch records
- Access modes: full, confirm, hard read-only
- Session lineage tracking with resume by exact provider ID
- Persistent Codex app-server supervisor
- Remote host delegation via SSH and domain inventory
- Domain development workflow with inventory resolution
- Team contracts: Turing/Fermat/Dewey/Faraday four-role mode
- Linux sandbox via bubblewrap filesystem projection
- Debian APT package and macOS Homebrew formula
- Minisign-signed release manifests with SBOM
